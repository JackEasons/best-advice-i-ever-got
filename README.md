One sentence, up to 200 characters, on the best advice I ever received. A judge model compares entries pairwise and the line that carries the most lived truth wins.

> My father told me a shortcut is only a debt wearing a smile, and the work always comes back to collect.

## Run it

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt`.
